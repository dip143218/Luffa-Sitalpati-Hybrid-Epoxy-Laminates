# Luffa–Sitalpati Hybrid Epoxy Laminates

## Overview

This repository contains experimental data associated with the study of Luffa–Sitalpati hybrid epoxy laminates. It is intended to support data transparency, reproducibility, and independent assessment of the experimental results reported in the associated research paper.

## Repository Contents

- `data/raw/tensile/` — Raw tensile test data for the available laminate configurations and pure epoxy.
- `data/raw/flexural/` — Raw flexural test data for the available laminate configurations.
- `data/raw/failure-images/` — Original photographs of specimens after flexural testing.
- `data/processed/` — Processed datasets and derived values, when available.
- `figures/` — Figures prepared for the associated research paper, when included.

## Material Configuration Labels

The dataset uses the configuration labels provided in the original experimental files. The meaning of each label and the laminate stacking sequence should be defined in the associated research paper.

## Data Integrity and Processing

Original experimental files are intended to be preserved separately from processed datasets and publication figures. Any derived mechanical properties should be interpreted using the equations, units, specimen dimensions, test conditions, and processing methods documented in the research paper.
